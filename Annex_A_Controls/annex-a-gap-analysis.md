# Annex A Gap Analysis  
This document evaluates NovaPay’s current implementation of ISO/IEC 27001:2022 Annex A controls and identifies gaps requiring remediation.

---

## 1. Purpose  
To provide a clear overview of which Annex A controls are:
- Fully implemented  
- Partially implemented  
- Not implemented  
- Not applicable  

This helps prioritise remediation and supports the Risk Treatment Plan.

---

## 2. Methodology  
Each control from Annex A.5, A.6, A.7, and A.8 is reviewed against:
- Existing policies  
- Existing procedures  
- Technical controls  
- Evidence availability  
- Operational maturity  

Status categories:
- **Implemented** – Control fully in place with evidence.  
- **Partially Implemented** – Control exists but incomplete or missing evidence.  
- **Not Implemented** – Control absent or not started.  
- **Not Applicable** – Control not relevant to NovaPay’s environment.

---

## 3. Summary of Findings  

### A.5 Organizational Controls  
- Implemented: 26  
- Partially Implemented: 8  
- Not Implemented: 3  
Key gaps:  
- Supplier security reviews  
- Records management automation  
- Threat intelligence integration maturity  

### A.6 People Controls  
- Implemented: 5  
- Partially Implemented: 2  
- Not Implemented: 1  
Key gaps:  
- Advanced role‑specific security training  
- Remote working monitoring improvements  

### A.7 Physical Controls  
- Implemented: 9  
- Partially Implemented: 4  
- Not Implemented: 1  
Key gaps:  
- Visitor access logging automation  
- Environmental monitoring sensors  

### A.8 Technological Controls  
- Implemented: 22  
- Partially Implemented: 10  
- Not Implemented: 2  
Key gaps:  
- Full SIEM correlation rules  
- Secure development lifecycle documentation  
- Vulnerability disclosure program maturity  

---

## 4. High‑Priority Gaps  
These gaps require immediate remediation:

- Supplier security evaluation process (A.5.19–A.5.23)  
- Secure development lifecycle (A.8.24–A.8.26)  
- Vulnerability management automation (A.8.15)  
- Physical access logging (A.7.2)  
- Key management documentation (A.8.23)

---

## 5. Recommendations  
- Strengthen supplier onboarding and monitoring.  
- Formalise secure coding and SDLC documentation.  
- Improve SIEM rules and alerting.  
- Deploy automated visitor logging systems.  
- Document key lifecycle processes (creation, rotation, destruction).

---

## 6. Review  
This gap analysis must be updated:  
- Annually  
- After major changes  
- Before internal or external audits
