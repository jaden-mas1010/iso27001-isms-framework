# Annex A Implementation Status  
This document tracks the implementation status of all ISO/IEC 27001:2022 Annex A controls across NovaPay’s ISMS.

---

## 1. Purpose  
To provide a real‑time overview of the implementation progress for all 93 Annex A controls, including evidence, ownership, and deadlines.

---

## 2. Status Categories  
- **Implemented** – Fully in place with evidence.  
- **Partially Implemented** – Exists but incomplete or missing evidence.  
- **Not Implemented** – Control not yet started.  
- **Not Applicable** – Not relevant to NovaPay’s environment.
