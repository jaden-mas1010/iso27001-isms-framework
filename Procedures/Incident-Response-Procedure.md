# Incident Response Procedure

## Purpose
To ensure NovaPay responds effectively to information security incidents.

## Phases

### 1. Identification
- Detect incidents via SOC alerts, logs, or user reports.
- Classify severity (Low, Medium, High, Critical).

### 2. Containment
- Isolate affected systems.
- Disable compromised accounts.
- Block malicious IPs.

### 3. Eradication
- Remove malware.
- Patch vulnerabilities.
- Reset credentials.

### 4. Recovery
- Restore systems from backups.
- Validate system integrity.
- Monitor for recurrence.

### 5. Lessons Learned
- Conduct root cause analysis.
- Update controls and documentation.

### 6. Reporting
- Internal reporting.
- Regulatory reporting within 72 hours (GDPR).
