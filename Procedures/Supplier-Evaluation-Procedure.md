# Supplier Evaluation Procedure

## Purpose
To ensure all third‑party suppliers, service providers, and cloud vendors used by NovaPay meet the organisation’s security, compliance, and operational requirements.

## Scope
All suppliers that:
- Process NovaPay data
- Provide IT or security services
- Host NovaPay systems or infrastructure
- Have access to NovaPay environments

## Roles & Responsibilities
- **Supplier Owner** – Manages the relationship and evaluation.
- **ISMS Manager** – Reviews security and compliance risks.
- **Procurement** – Ensures contractual requirements are met.
- **DPO** – Reviews privacy and data protection risks.

---

## 1. Initial Supplier Assessment
Before onboarding any supplier, NovaPay must perform:

### 1.1 Security Questionnaire
Collect information on:
- Security controls  
- Certifications (ISO 27001, SOC2, PCI DSS)  
- Data protection practices  
- Incident response capabilities  

### 1.2 Risk Classification
Suppliers are classified as:
- **High Risk** – Access to sensitive data or critical systems  
- **Medium Risk** – Access to internal systems or non‑critical data  
- **Low Risk** – No access to NovaPay systems or data  

### 1.3 Technical Review
Evaluate:
- Encryption  
- Access controls  
- Logging and monitoring  
- Network security  
- Cloud configuration (if applicable)

---

## 2. Contractual Requirements
All supplier contracts must include:

### Mandatory Clauses
- Confidentiality  
- Data protection (GDPR/DPA 2018)  
- Breach notification within 24 hours  
- Right to audit  
- Security requirements aligned with ISO 27001  

### Additional Clauses for High‑Risk Suppliers
- Mandatory ISO 27001 or SOC2 Type II certification  
- Detailed SLAs for uptime and security  
- Business continuity and disaster recovery requirements  

---

## 3. Ongoing Monitoring
### 3.1 Annual Supplier Review
High‑risk suppliers must undergo:
- Annual security questionnaire  
- Review of certifications  
- Review of incident history  
- Review of SLA performance  

Medium‑risk suppliers reviewed every 2 years.  
Low‑risk suppliers reviewed every 3 years.

### 3.2 Performance Monitoring
Track:
- SLA compliance  
- Support responsiveness  
- Security incidents  
- Service outages  

### 3.3 Incident Reporting
Suppliers must report:
- Security incidents  
- Data breaches  
- Operational disruptions  
Immediately to NovaPay’s ISMS Manager.

---

## 4. Supplier Termination
When ending a supplier relationship:

### 4.1 Secure Data Return or Deletion
Supplier must:
- Return all NovaPay data securely  
- Provide deletion certificates  
- Revoke all access to NovaPay systems  

### 4.2 Access Removal
NovaPay must:
- Disable supplier accounts  
- Remove API keys  
- Remove VPN access  
- Remove shared credentials  

### 4.3 Documentation
Record:
- Termination date  
- Reason  
- Data deletion evidence  
- Access removal confirmation
