# Change Management Procedure

## Purpose
To ensure all changes to NovaPay’s systems, applications, infrastructure, and security controls are planned, reviewed, approved, tested, implemented, and documented in a controlled manner.

## Scope
All production systems, cloud environments, applications, network devices, and security configurations.

## Roles & Responsibilities
- **Change Requester** – Submits the change.
- **Change Owner** – Manages the change lifecycle.
- **ISMS Manager** – Reviews security impact.
- **Approver (CTO / IT Manager)** – Approves high‑risk changes.
- **IT Operations** – Implements changes.

---

## 1. Change Request Submission
All changes must include:
- Description of change  
- Reason for change  
- Systems affected  
- Risk level (Low / Medium / High)  
- Rollback plan  
- Scheduled implementation date  

Requests are logged in the Change Register.

---

## 2. Review & Approval
### Low‑risk changes  
Approved by Change Owner.

### Medium‑risk changes  
Approved by ISMS Manager.

### High‑risk changes  
Approved by CTO or senior management.

Security impact must be assessed for:
- Access control changes  
- Network changes  
- Cloud configuration changes  
- Production deployments  

---

## 3. Testing
Before implementation:
- Test in staging environment  
- Validate functionality  
- Validate security impact  
- Confirm rollback plan works  

Testing evidence must be documented.

---

## 4. Implementation
- Implement change during approved window  
- Notify affected teams  
- Monitor systems during and after change  
- Apply rollback if issues occur  

All actions must be logged.

---

## 5. Documentation
After implementation:
- Update configuration records  
- Update asset inventory  
- Update diagrams (if applicable)  
- Update procedures or policies (if impacted)  

---

## 6. Post‑Implementation Review
Within 48 hours:
- Confirm change success  
- Check for unexpected issues  
- Validate security controls  
- Document lessons learned  

---

## Review
This procedure must be reviewed annually or after major incidents.
