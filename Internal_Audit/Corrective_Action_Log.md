# 2. Corrective Action Workflow

1. **Identify Issue**  
   - Audit finding  
   - Incident  
   - Risk assessment  
   - Supplier review  

2. **Root Cause Analysis**  
   - Human error  
   - Process gap  
   - Technical misconfiguration  
   - Missing documentation  

3. **Define Corrective Action**  
   - What must be changed  
   - Who owns the action  
   - Deadline  

4. **Implement Action**  
   - Update process  
   - Apply technical fix  
   - Train staff  
   - Update documentation  

5. **Verify Closure**  
   - Evidence reviewed  
   - ISMS Manager approves closure  

---

# 3. Status Definitions

- **Not Started** – Action identified but no work begun  
- **In Progress** – Work underway  
- **Completed** – Action fully implemented with evidence  
- **Overdue** – Deadline missed  

---

# 4. Review

This log must be reviewed:
- Monthly  
- After internal audits  
- After major incidents  
- Before external certification audits
